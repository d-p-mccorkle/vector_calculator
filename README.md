# Path
## A simple TUI vector calculator.

## Description:
  Path is a terminal based calculator for vector math.  It is currently a work in progress, and is quite unformed.  The  finished product will consist of a UI created with Textual to interact with an underlying vector calculator which uses SymPy to handle exact solutions.  The vector module itself is not the SymPy module but one made by d-p-mccorkle.

## Use and Purpose:
  Frankly this is a learning exercise more than anything.  It is however designed to be a functional calculator for simple operations involving vectors.  It was designed with use during homework in mind and would be suitable for use with classical mechanics problems.

## Contributions:
